## Browser Assets

Compiled browser assets include code from the npm dependencies declared in `package.json`. Their source packages, versions, integrity hashes, and license metadata are recorded by `package-lock.json` in the source repository. Production npm dependencies are GPL-compatible permissive packages (MIT, ISC, BSD, Apache-2.0, and Unicode licenses).
